เข้าสู่ระบบผู้ดูแล

ระบบจัดการโปรแกรมเสริม, License Key และข้อความหน้าเว็บ

ยอดขายรวม (ทั้งหมด) ฿0 คำนวณจากออเดอร์จริงในระบบ
License Keys ที่เปิดใช้ 0 Keys พร้อมระบบ Node-Locked HWID
รายการโปรแกรมทั้งหมด 0 โปรแกรม พร้อมขายบนสโตร์
คีย์ที่ถูกปลดล็อก (พร้อมย้าย) 0 Keys ปลดล็อกเพื่อย้ายเครื่องใหม่

รายการโปรแกรมเสริมในสโตร์

เพิ่ม แก้ไขราคา ปรับสถานะ หรือลบโปรแกรม (บันทึกข้อมูลจริงอัตโนมัติ)
รหัสสินค้า (SKU)ชื่อโปรแกรมโปรแกรมที่รองรับราคาขายยอดขายสถานะจัดการ

ทะเบียน License Key และผูกเครื่อง

ตรวจสอบสิทธิ์ ปลดล็อกย้ายเครื่อง ระงับสิทธิ์ หรือออกคีย์ใหม่
License Keyโปรแกรมอีเมลลูกค้าMachine ID (HWID)วันที่สร้างสถานะจัดการ

ประวัติรายการชำระเงิน (PromptPay Gateway)

ตรวจสอบยอดเงินและสถานะส่งมอบคีย์อัตโนมัติ 24 ชม.
Order IDลูกค้าสินค้ายอดเงินช่องทางเวลาสถานะจัดการ

แก้ไขข้อความบนหน้าเว็บจริง (Direct Visual Editor)

คลิกที่ตัวหนังสือบนหน้าเว็บด้านล่างนี้ได้โดยตรงเพื่อพิมพ์แก้ไขข้อความได้ทันที เมื่อแก้ไขเสร็จแล้วกดปุ่มบันทึก
วิธีใช้งาน: เอาเมาส์คลิกที่หัวข้อ, คำอธิบาย, ราคา หรือปุ่มบนหน้าเว็บด้านล่างนี้ แล้วพิมพ์แก้ไขตัวหนังสือได้สดๆ จากนั้นกดปุ่ม "บันทึกข้อความทั้งหมด"
